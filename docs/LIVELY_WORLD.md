# Making Tessera feel alive

Target: a world as busy and cheerful as the classic voxel action-RPGs that inspired
Tessera, built from **our own** original names, models, text and music.
This list comes from studying how those games present their worlds (sources at the end)
and from the reference screenshot Sandra shared. Each item says when we build it.

## 1. Villages (the heart of "alive")

- [x] A village always near the starting point; more villages scattered in every biome. *(next round)*
- [x] Village layout: a central paved plaza, houses with pitched roofs and windows, fences,
      flower pots, benches, tables, lamp posts, crop fields (sunflowers, wheat), a well. *(next round)*
- [x] A **trade district**: weapon smith, armourer, general goods shop (potions, pet food,
      materials), each with a stall/awning and a vendor standing behind it. *(next round + loot round)*
- [ ] Class trainers (one per class) for specializations. *(skills round)*
- [ ] Crafting buildings: forge, kitchen, alchemy table, loom. *(crafting round)*
- [x] Biome-styled villages (snowy cabins, desert adobe, marsh stilt houses, stone in the peaks).
- [x] Village name shown under the region name when you enter. *(next round)*

## 2. NPCs that behave like people

- [x] Procedural villagers: varied faces, hair, clothes, heights (no two alike). *(next round)*
- [x] Daily routine: wander the plaza by day, go indoors at night, a few guards stay out. *(next round)*
- [x] Stop and turn to face you when you come close; "E — Talk" prompt. *(next round)*
- [x] Speech bubbles over heads with short lines (greetings, rumours about nearby
      dungeons, lore about original kingdoms/clans). *(next round)*
- [ ] Quest givers marked with a coloured bubble above their head. *(quests round)*
- [x] A small chat/log window (bottom right) recording conversations and events. *(next round)*
- [ ] Travelling NPCs met on roads; friendly wanderers in the wild.

## 3. Wildlife and creatures

- [ ] Peaceful animals that wander and flee (rabbit-, deer-, sheep-, bird-like originals). *(creatures round)*
- [ ] Tameable animals (fed with a specific food), fighting or rideable pets. *(pets round)*
- [ ] 3+ enemies per biome with different behaviours (charger, ranged, swarm, ambusher). *(creatures round)*
- [ ] Rare elite enemies with a glowing aura; boss creatures shown on the minimap by their head.
- [ ] Night-only creatures. *(creatures round)*

## 4. Ambient motion (the world never stands still)

- [x] Leaves gently swaying, grass tufts and flowers on the ground. *(next round)*
- [ ] Water waves / shimmer; frozen lakes with slippery ice.
- [x] Moving clouds overhead (not only the cloud sea in rifts). *(next round)*
- [ ] Weather: rain in marsh and meadows, snow in frost and peaks, sandstorms in dunes.
- [x] Particles: dust when landing/rolling, splashes, sparks on hits, fireflies at night,
      glowing motes around crystals. *(next round: hits + landing; later: the rest)*
- [x] Butterflies by day, fireflies by night.

## 5. HUD in the reference style

- [x] Chunky pixel-style font (drawn in code, no downloads) for HUD labels. *(next round)*
- [x] Gold counter with coin icon, top-left. *(loot round)*
- [x] Top-right: region name, village/place name, and a **3D minimap** that turns with the
      camera and reveals tiles as you explore; bosses and quest givers shown as icons. *(next round: minimap)*
- [x] Info line: coordinates, time, temperature (by biome and time), zoom.
- [x] HP / MP bars at the bottom centre, framed, with numbers. *(done; restyle next round)*
- [ ] Quick-use slots bottom-left (potions, traps) with key hints. *(loot round)*
- [x] Interaction prompts ("E Talk", "E Open", "E Pick up"). *(next round)*

## 5b. Detail pass (done)

- [x] Brighter, saturated palette; two-tone grass blocks; terraced terrain; big two-tone trees
- [x] Expressive characters: big eyes, brows, cheeks, hands, boots, two-tone hair, ear types
- [x] Four original villager peoples (humans, elves, Mossfolk, Brindlefolk)
- [x] Props: doors, shutters, flower boxes, pots, barrels, crates, furniture, stall goods, pavilion
- [x] Wild props: rocks, boulders, mushrooms, logs, berry bushes; chimney smoke
- [x] Clean HUD: portrait, small bars, compass, hotbar with icons and cooldowns; 3D diorama minimap

## 6. Things to find

- [ ] Treasure chests in ruins and dungeons; collectible plants and ore you see in the world.
- [ ] Ruins, watchtowers, camps, shrines, statues; dungeons (catacombs, temples, pyramids, castles).
- [ ] Artifacts with a short lore line (original kingdoms) that boost travel skills.
- [ ] Discoverable landmarks named on the map.
